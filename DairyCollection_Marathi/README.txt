दुग्ध संकलन (DAIRY COLLECTION) - पूर्ण मराठी ॲप
=================================================

GITHUB वरून APK कसा बनवायचा
1. ही ZIP फाईल Extract करा. आतील सर्व फाईल्स व फोल्डर (.github सहित) तुमच्या GitHub repository च्या मुख्य (root) जागी अपलोड करा.
2. GitHub > Actions > "Build APK" उघडा. (push केल्यावर आपोआप चालते; किंवा "Run workflow" दाबा.)
3. ३-५ मिनिटांनी काम संपल्यावर त्या run मध्ये खाली "Artifacts" मध्ये DairyCollection-debug-apk डाउनलोड करा.
4. ZIP मधून app-debug.apk काढा, फोनवर install करा.

OTP मालकाच्या जीमेलवर येण्यासाठी (शिफारस)
1. मालकाच्या जीमेलमध्ये लॉगिन करून script.google.com > New project उघडा.
2. OtpEmailScript.gs मधील सर्व मजकूर पेस्ट करा. (SECRET आधीच सेट केलेला आहे, तो बदलू नका.)
3. Deploy > New deployment > Web app > Execute as: Me, Who has access: Anyone. Authorize करून /exec ने संपणारा URL कॉपी करा.
4. app/src/main/java/com/example/dairy/Auth.kt मध्ये  OTP_URL = "..."  या ठिकाणी तो URL टाका. (OTP_SECRET तोच राहू द्या.)
5. GitHub वर बदल save (commit) करा, APK पुन्हा आपोआप तयार होईल.
OTP_URL रिकामा असल्यास OTP मालकाच्या मोबाईलवर SMS ने जातो (Auth.kt मध्ये OWNER_MOBILE). Android 13+ वर APK ने install केलेल्या ॲपमध्ये SMS बंद असू शकतो, म्हणून जीमेल पद्धत वापरा.

स्क्रीन
 लॉगिन > मुख्य पान (आजचे एकूण)
 १. माहिती अपलोड      : ग्राहक .txt फाईल निवडा (नाव, ग्राहक क्रमांक, मोबाईल)
 २. दूध संकलन नोंद     : ग्राहक, तारीख, सकाळ/संध्याकाळ, गाय/म्हैस, लिटर, फॅट, SNF, डिग्री, दर > जतन करा
 ३. माहिती एक्स्पोर्ट    : तारीख निवडा > टेक्स्ट फाईल डाउनलोड (Downloads फोल्डरमध्ये)
 ४. दैनिक अहवाल        : तारीख निवडा, एकूण पाहा, अहवाल छापा
 ५. पावती पुन्हा छापा     : नोंदीवर दाबा > डुप्लिकेट प्रत छापा
 ६. प्रिंटर              : आधी फोनच्या ब्लूटूथमध्ये प्रिंटर पेअर करा, नंतर इथे निवडा

ग्राहक फाईल
 - KF-Kiran (जुनी ANSI फाईल): "फाईलमधील नावे KF-Kiran आहेत" हा चौकोन चालू ठेवा. फॉन्ट app/src/main/assets/fonts/KF-Kiran.ttf मध्ये आधीच घातला आहे.
 - Unicode मराठी (उदा. customers_sample_marathi.txt) किंवा इंग्रजी नावे: ॲप स्वतः ओळखते.
 - SMS व डायलॉगमध्ये KF-Kiran नावे वाचता येत नाहीत, म्हणून तिथे "ग्राहक क्र. १०१" दाखवला जातो.

दुकानाचे नाव (पावतीवर): Store.kt > SHOP_NAME
80mm कागदासाठी: Printer.kt > DOTS = 576
मराठी SMS Unicode असल्यामुळे एका SMS मध्ये ७० अक्षरे बसतात; मोठा मजकूर २-४ SMS म्हणून जातो.
Android Studio मध्येही File > Open ने हा फोल्डर उघडून Run करता येतो.
